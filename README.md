# NOVA Island

Плавающий «остров» для Windows и Linux: сбрасывай туда файлы, сохраняй заметки и возвращайся к недавно скопированному — не переключаясь между окнами. Текущая версия проекта: **1.7.1**.

## Что умеет

- **Компактная верхняя капсула** — время, текущие CPU/RAM и погода выбранного города; панель остаётся поверх окон. Раскрытое окно можно перетаскивать за верхнюю шапку, NOVA запоминает позицию и восстанавливает её при следующем открытии.
- **Файлы и папки** — отдельная вкладка для документов, изображений и медиа; создавай папки и раскладывай по ним копии. Файл можно добавить через кнопку или перетащить на остров; NOVA сохраняет свою локальную копию.
- **Встроенный медиаплеер** — файлы `.mp3`, `.mp4`, `.mpg`, `.ogg`, `.wav` открываются в NOVA; в панели есть воспроизведение, пауза, перемотка, громкость и отключение звука. В свёрнутой капсуле при наведении показываются Prev/Play-Pause/Next и бегущая строка названия; по завершении трек переключается дальше. Декодирование зависит от кодека внутри файла и поддержки Electron/Windows.
- **История буфера** — пока NOVA запущена, локально сохраняет скопированный текст, изображения и файлы. При изменении буфера капсула кратко расширяется и показывает тип содержимого, не раскрывая его текст. Скопированный файл можно вставить в Проводник или другое окно. Запись можно поставить на паузу или очистить.
- **Заметки и быстрый текст** — сохраняй мысли, фрагменты и ссылки.
- **Коллекция по категориям** — отдельные разделы «Файлы», «Буфер», «Заметки», «Медиа» и «Избранное» с живыми счётчиками. В файлах есть подкатегории «Документы / Изображения», в буфере — «Текст / Изображения / Файлы». Поиск работает внутри выбранной категории; сортировка — по новизне, имени или размеру.
- **Новый планировщик** — отдельная вкладка «План» с личными задачами, сроками «сегодня/завтра/без срока», списками «Сегодня / Все / Готово» и круговым прогрессом. Задачи хранятся локально, до 120 штук; данные включаются в резервную копию.
- **Просмотр буфера** — текстовые элементы можно раскрыть прямо в списке и прочитать целиком; быстрые действия позволяют поставить запись буфера на паузу, не уходя в настройки.
- **Оформление** — темы «Аметист», «Океан» и «Закат», произвольный цвет подсветки и опциональный режим **Liquid Glass** с прозрачностью, бликами и размытием.
- **Живой дождь на рабочем столе** — прозрачный сквозной слой поверх окон и меню «Пуск». Капли ускоряются под действием гравитации, сливаются, скользят по верхним краям видимых окон и оставляют всплески/кольца; интенсивность настраивается. Для каждого монитора создаётся отдельный слой, включая дисплеи слева/справа и выше/ниже основного; окна отслеживаются во время работы. Мышь проходит насквозь, а полноэкранный игровой режим скрывает слой.
- **Резервная копия** — экспорт/импорт заметок, задач, закреплений и вложенных файлов; импорт объединяет записи и не стирает текущие данные. Вложения до 128 МБ.
- **Локальное хранилище** — показывает число файлов и объём копий; потерянные файлы в папке NOVA можно проверить и удалить после подтверждения. Исходники вне папки NOVA не затрагиваются.
- **Система и погода** — метрики CPU/RAM также показываются в капсуле; подробные графики и датчики остаются во вкладке «Система». Погода берётся из MET Norway для выбранного города (по умолчанию — Хабаровск); название города отправляется сервису геокодирования только при явном поиске. Оффлайн погода скрывается до восстановления сети.
- **Командный пульт** — добавляй ярлыки приложений для быстрого запуска; доступны скриншот всей области экрана или выделенного фрагмента (сохранение в PNG или копирование), запись экрана в WebM и отдельная запись микрофона. Для записи микрофона требуется одноразовое подтверждение; системный звук в видеозаписи выключен по умолчанию и включается отдельно. В Windows можно выполнить введённую команду в административном CMD: NOVA показывает её перед запуском, затем Windows запрашивает UAC. Используй только команды, которым доверяешь. Базовые действия системы ограничены безопасными сценариями.
- **Микрофон** — режим индикатора анализирует уровень звука локально и не записывает его. Отдельная запись звука работает только после подтверждения, сохраняется на выбранный пользователем диск и никуда не отправляется автоматически.
- **Интеграция с Windows** — сквозные клики в свёрнутом режиме, игровой режим скрытия поверх полноэкранных окон, колесо мыши для громкости и Shift+колесо для яркости встроенного дисплея. Эти функции Windows-зависимы; яркость может быть недоступна у внешних мониторов.
- **Горячие клавиши** — `Ctrl + Shift + Space` показать/скрыть, `Ctrl + N` новая заметка, `Ctrl + Shift + N` быстрый текст, `Ctrl + K` поиск; цифры `1–6` переключают фильтры.
- **Без облака** — локальные данные остаются на этом компьютере.

> История буфера может сохранить всё, что попадает в буфер обмена. Не копируй в него пароли и секретные ключи; при необходимости выключай запись в настройках NOVA. Административные команды имеют полный доступ в рамках Windows UAC — внимательно проверяй текст команды перед подтверждением. Записи и скриншоты не загружаются автоматически.
>
> Обычная NSIS-установка Electron не имеет права читать и подменять системные уведомления Telegram/Discord. Для этого Windows требует упакованную MSIX-сборку с отдельной capability и разрешением пользователя. NOVA не перехватывает чужие системные уведомления.

## Быстрая проверка

Для Windows-сборки требуется Windows 10/11 x64; для Linux — x86_64. Node.js 22.12 или новее нужен только для запуска/сборки из исходников.

1. Установи Node.js 22.12 или новее и распакуй папку проекта.
2. Windows: запусти `run-windows.bat`. Linux: выполни `npm ci && npm start`.

## Собрать установщик `.exe`

На Windows запусти **`build-windows.bat`**. Скрипт установит зависимости и соберёт NSIS-установщик в `release\`.

То же вручную из папки проекта:

```bat
npm install
npm run dist:win
```

После сборки запусти `NOVA-Island-Setup-1.7.1-x64.exe` из `release\`. Установщик создаёт ярлык на рабочем столе и в меню «Пуск»; права администратора по умолчанию не требуются. При первом запуске Windows может показать предупреждение SmartScreen: приложение не подписано сертификатом издателя.

Для портативной сборки Windows можно выполнить `npm run dist:win:portable`.

## Linux AppImage

Скачай `NOVA-Island-1.7.1-x86_64.AppImage` из Releases, сделай файл исполняемым и запусти:

```bash
chmod +x NOVA-Island-1.7.1-x86_64.AppImage
./NOVA-Island-1.7.1-x86_64.AppImage
```

Для запуска AppImage системе обычно нужна поддержка FUSE 2 (на Ubuntu/Debian пакет `libfuse2`). Если FUSE недоступен, попробуй `./NOVA-Island-1.7.1-x86_64.AppImage --appimage-extract-and-run`. На Linux недоступны Windows-специфичные функции, такие как UAC, перезапуск Проводника и управление яркостью встроенного дисплея.

Собрать пакет из исходников можно на Linux x86_64:

```bash
npm ci
npm run dist:linux
```

## Использование

- Нажми на капсулу, чтобы развернуть NOVA; нажми на стрелку или `Esc`, чтобы свернуть.
- Нажми `Ctrl + Shift + Space`, чтобы показать/скрыть остров из любого окна. `Ctrl + N` создаёт заметку, `Ctrl + Shift + N` — текст, `Ctrl + K` — поиск.
- Коллекция по умолчанию открывает **Буфер**. Выбирай категорию, нажимай значок глаза у текстовой записи, чтобы развернуть её целиком; сортировку можно менять по дате, имени или размеру.
- Во вкладке **«Файлы»** создай папки, добавь документы/изображения/музыку и назначай им папки через список на карточке.
- Во вкладке **«Пульт»** добавляй приложения, делай скриншоты, записывай экран/микрофон и запускай административные команды с явным подтверждением UAC.
- Во вкладке **«План»** добавляй задачи, назначай срок и отмечай готовое; завершённые и будущие дела находятся в фильтрах.
- В настройках выбери тему и создай резервную копию. Импорт копии объединяет задачи и элементы, не удаляя текущие.
- Перетащи файлы или текст прямо на свёрнутый остров: он раскрывается, подсвечивается и принимает содержимое. В настройке «Сквозные клики» перетаскивание отключается; для открытия NOVA используй горячую клавишу или трей.
- Закрепляй заметки, текст, файлы и медиафайлы булавкой; список закреплённого доступен через фильтр **«Закреплённое»**.
- Нажатие на обычный файл открывает его. Нажатие на аудио/видео запускает его во встроенном плеере; наведи курсор на свёрнутую капсулу для Prev/Play-Pause/Next.
- Колесо мыши над свёрнутым островом регулирует системную громкость, `Shift + колесо` — яркость встроенного дисплея. В развернутой панели колесо остаётся обычной прокруткой.
- Во вкладке **«Сеть и скрипты»** доступны аппаратные показатели, GitHub-релиз/коммит, ping и ограниченные системные действия.
- Мониторинг микрофона по умолчанию выключен. Перед записью экрана можно выбрать монитор; системный звук видео выключен по умолчанию и включается отдельным флажком. Микрофон запрашивается отдельным одноразовым подтверждением.
- В настройках можно включить сквозные клики и игровой режим. Сквозной режим пропускает мышь, но не принимает клики и перетаскивание; для вызова используй `Ctrl + Shift + Space` или трей.
- Кнопка копирования у файла или медиа кладёт в буфер сам файл (его можно вставить в Проводник), у изображения — картинку, у текста — текст.
- В **Настройки → Локальное хранилище** доступны размер копий, открытие папки NOVA и безопасная очистка потерянных копий.
- Закрытие панели оставляет NOVA в области уведомлений. Чтобы выйти полностью, выбери **«Выход»** в меню значка NOVA или **«Выйти из NOVA»** в настройках.

Файлы копируются в пользовательскую папку данных приложения. Её можно открыть из **Настройки → Открыть папку файлов**. Удаление карточки файла удаляет его копию из хранилища NOVA, но не исходный файл.

## Структура проекта

- `main.js` — окно, системный трей, IPC, буфер обмена, локальное хранилище и разрешённые системные действия.
- `system-services.js` — изолированные службы мониторинга, GitHub, ping и Windows-интеграции.
- `task-utils.js` — нормализация, проверка дат и ограничение размера локального плана.
- `preload.js` — ограниченный безопасный мост между интерфейсом и Electron.
- `index.html` — интерфейс, стили, категории, файловая вкладка и пульт захвата/записи.
- `rain.html` и `rain-preload.js` — прозрачный интерактивный дождевой слой поверх рабочего стола.
- `tests/system-services.test.js` и `tests/task-utils.test.js` — проверки системных служб, дат, ограничений и локальных задач.
- `assets/` — иконки приложения и системного трея.
- `build-windows.bat` — сборка установщика Windows.

## UI-ориентир

Идеи компактной Dynamic Island-капсулы и панели инструментов подсмотрены в публичном описании [Island от exuupery](https://github.com/exuupery/island). NOVA сохраняет собственный дизайн и архитектуру: исходный код и графические ресурсы проекта не копировались.
