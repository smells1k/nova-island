# NOVA Island

Небольшой плавающий «остров» для Windows: сбрасывай туда файлы, сохраняй заметки и возвращайся к недавно скопированному — не переключаясь между окнами.

## Что умеет

- **Плавающая панель поверх окон** — компактная капсула у верхнего края экрана, разворачивается в рабочее пространство.
- **Файловый карман** — перетаскивание файлов или добавление через кнопку; NOVA сохраняет собственную копию, открывает файл и показывает его в Проводнике.
- **История буфера** — пока NOVA запущена, локально сохраняет скопированный текст, изображения и файлы. Скопированный файл можно вставить в Проводник или другое окно. Запись можно поставить на паузу или очистить.
- **Заметки и быстрый текст** — сохраняй мысли, фрагменты и ссылки.
- **Поиск, фильтры, закрепление и удаление** — всё важное под рукой.
- **Горячая клавиша** `Ctrl + Shift + Space`, значок в области уведомлений и опциональный запуск вместе с Windows.
- **Локальное хранение** — без учётной записи и облачной синхронизации.

> История буфера может сохранить всё, что попадает в буфер обмена. Не копируй в него пароли и секретные ключи; при необходимости выключай запись в настройках NOVA.

## Быстрая проверка

Требуется Windows 10/11 x64 и Node.js 22.12 или новее.

1. Распакуй папку проекта.
2. Запусти `run-windows.bat` — он установит зависимости и откроет приложение в режиме разработки.

## Собрать установщик `.exe`

На Windows запусти **`build-windows.bat`**. Скрипт установит зависимости и соберёт NSIS-установщик в `release\`.

То же вручную из папки проекта:

```bat
npm install
npm run dist:win
```

После сборки запусти `NOVA-Island-Setup-1.0.0-x64.exe` из `release\`. Установщик создаёт ярлык на рабочем столе и в меню «Пуск»; права администратора по умолчанию не требуются. При первом запуске Windows может показать предупреждение SmartScreen: приложение не подписано сертификатом издателя.

Для портативной сборки можно выполнить `npm run dist:win:portable`.

## Использование

- Нажми на капсулу, чтобы развернуть NOVA; нажми на стрелку или `Esc`, чтобы свернуть.
- Нажми `Ctrl + Shift + Space`, чтобы показать/скрыть остров из любого окна.
- Перетащи в панель файлы или текст. Для файлов также есть кнопка **«Файл»**.
- Нажатие на карточку открывает файл. Кнопка копирования у файла кладёт в буфер сам файл (его можно вставить в Проводник), у изображения — картинку, у текста — текст.
- Закрытие панели оставляет NOVA в области уведомлений. Чтобы выйти полностью, выбери **«Выход»** в меню значка NOVA или **«Выйти из NOVA»** в настройках.

Файлы копируются в пользовательскую папку данных приложения. Её можно открыть из **Настройки → Открыть папку файлов**. Удаление карточки файла удаляет его копию из хранилища NOVA, но не исходный файл.

## Структура проекта

- `main.js` — окно, системный трей, локальное хранилище, буфер обмена и файловые операции.
- `preload.js` — небольшой безопасный мост между интерфейсом и Electron.
- `index.html` — интерфейс, стили и анимации; в обычном браузере открывается интерактивное демо.
- `assets/` — иконки приложения и системного трея.
- `build-windows.bat` — сборка установщика Windows.
