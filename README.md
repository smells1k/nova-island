# NOVA Island

Плавающий «остров» для Windows: сбрасывай туда файлы, сохраняй заметки и возвращайся к недавно скопированному — не переключаясь между окнами. Текущая версия проекта: **1.2.0**.

## Что умеет

- **Плавающая панель** — прозрачная капсула без квадратной рамки у верхнего края экрана. При закреплении она автоматически раскрывается, а после сворачивания становится шире, чтобы показать закреплённое; Windows-область окна обрезается по скруглённой форме.
- **Файловый карман** — перетаскивание файлов или добавление через кнопку; NOVA сохраняет собственную копию, открывает файл и показывает его в Проводнике.
- **Встроенный медиаплеер** — файлы `.mp3`, `.mp4`, `.mpg`, `.ogg`, `.wav` открываются в NOVA; в панели есть воспроизведение, пауза, перемотка, громкость и отключение звука. Активный медиафайл автоматически закрепляется, а в свёрнутом острове остаётся кнопка play/pause. Реальное декодирование зависит от кодека внутри файла и поддержки в Electron/Windows.
- **История буфера** — пока NOVA запущена, локально сохраняет скопированный текст, изображения и файлы. Скопированный файл можно вставить в Проводник или другое окно. Запись можно поставить на паузу или очистить.
- **Заметки и быстрый текст** — сохраняй мысли, фрагменты и ссылки.
- **Поиск, фильтры, закрепление и удаление** — закреплённый элемент автоматически раскрывает остров, остаётся сверху списка, а в широкой свёрнутой капсуле виден его заголовок и число остальных закреплений.
- **Таймер фокуса** — Pomodoro на 15, 25 или 50 минут, короткий перерыв на 5 минут, пауза/сброс и уведомление по завершении. Обратный отсчёт продолжает идти, даже если капсула свёрнута.
- **Три темы оформления** — «Аметист», «Океан» и «Закат».
- **Резервная копия** — экспорт/импорт заметок, закреплений и вложенных файлов; импорт сливает записи и не стирает текущие данные. Вложения до 128 МБ.
- **Локальное хранилище** — показывает число файлов и объём копий; потерянные файлы в папке NOVA можно проверить и удалить после подтверждения. Исходники вне папки NOVA не затрагиваются.
- **Горячие клавиши** — `Ctrl + Shift + Space` показать/скрыть, `Ctrl + N` новая заметка, `Ctrl + Shift + N` быстрый текст, `Ctrl + K` поиск; цифры `1–6` переключают фильтры.
- **Без облака** — локальные данные остаются на этом компьютере.

> История буфера может сохранить всё, что попадает в буфер обмена. Не копируй в него пароли и секретные ключи; при необходимости выключай запись в настройках NOVA.

## Быстрая проверка

Требуется Windows 10/11 x64 и Node.js 22.12 или новее.

1. Распакуй папку проекта.
2. Запусти `run-windows.bat` — он установит зависимости и откроет приложение в режиме разработки.

## Собрать установщик `.exe`

На Windows запусти **`build-windows.bat`**. Скрипт установит зависимости и соберёт NSIS-установщик в `release\`.

То же вручную из папки проекта:

```bat
npm install
npm run dist:win
```

После сборки запусти `NOVA-Island-Setup-1.2.0-x64.exe` из `release\`. Установщик создаёт ярлык на рабочем столе и в меню «Пуск»; права администратора по умолчанию не требуются. При первом запуске Windows может показать предупреждение SmartScreen: приложение не подписано сертификатом издателя.

Для портативной сборки можно выполнить `npm run dist:win:portable`.

## Использование

- Нажми на капсулу, чтобы развернуть NOVA; нажми на стрелку или `Esc`, чтобы свернуть.
- Нажми `Ctrl + Shift + Space`, чтобы показать/скрыть остров из любого окна. `Ctrl + N` создаёт заметку, `Ctrl + Shift + N` — текст, `Ctrl + K` — поиск.
- Запусти фокус-таймер в карточке «Фокус»; выбери 15/25/50 минут или короткий 5-минутный перерыв. Таймер доступен и в свёрнутой капсуле.
- В настройках выбери тему и создай резервную копию. Импорт копии добавляет данные, не удаляя текущие.
- Перетащи в панель файлы или текст. Для файлов также есть кнопка **«Файл»**.
- Закрепляй заметки, текст, файлы и медиафайлы булавкой; список закреплённого доступен через фильтр **«Закреплённое»**.
- Нажатие на обычный файл открывает его. Нажатие на аудио/видео запускает его во встроенном плеере; при свёрнутой панели play/pause доступен прямо на капсуле.
- Кнопка копирования у файла или медиа кладёт в буфер сам файл (его можно вставить в Проводник), у изображения — картинку, у текста — текст.
- В **Настройки → Локальное хранилище** доступны размер копий, открытие папки NOVA и безопасная очистка потерянных копий.
- Закрытие панели оставляет NOVA в области уведомлений. Чтобы выйти полностью, выбери **«Выход»** в меню значка NOVA или **«Выйти из NOVA»** в настройках.

Файлы копируются в пользовательскую папку данных приложения. Её можно открыть из **Настройки → Открыть папку файлов**. Удаление карточки файла удаляет его копию из хранилища NOVA, но не исходный файл.

## Структура проекта

- `main.js` — окно, системный трей, локальное хранилище, буфер обмена и файловые операции.
- `preload.js` — небольшой безопасный мост между интерфейсом и Electron.
- `index.html` — интерфейс, стили и анимации; в обычном браузере открывается интерактивное демо.
- `assets/` — иконки приложения и системного трея.
- `build-windows.bat` — сборка установщика Windows.
